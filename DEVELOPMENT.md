# Development

Setup authors: see [docs/authoring-setup.md](docs/authoring-setup.md). End-user install: [README.md](README.md).

```mermaid
flowchart LR
  pkg["packages/wtc: src/cli (thin CLI) -> src/* (logic)"] -. embeds .-> kit["kit/ (bash + Go wtc-kit)"]
  ex["examples/setup-basic"] -. tested by .-> pkg
```

- **Install:** `bun install`
- **Test:** `bun test` (integration tests only with `WTC_INTEGRATION=1`); the skill test ([packages/wtc/test/cli/skill.test.ts](packages/wtc/test/cli/skill.test.ts)) fails if SKILL.md misses a command or error code.
- **Integration tests (real docker):** `WTC_INTEGRATION=1 bun test examples/setup-basic` runs [examples/setup-basic/test/integration.test.ts](examples/setup-basic/test/integration.test.ts) against the example setup [examples/setup-basic](examples/setup-basic) (copied under `~/.cache/wtc-it/` because colima only shares `$HOME`; id `wtcit`, socks ports 22080-22179, host port 16379 must be free). `afterAll` removes every `wtc.setup=wtcit` container/volume and the `wtc-wtcit` image (`WTC_IT_KEEP_IMAGE=1` keeps the image).
- **Agent end-to-end (real logins, spends tokens):** `WTC_AGENT_E2E=1 bun test examples/setup-basic/test/agent.e2e.test.ts` runs [agent.e2e.test.ts](examples/setup-basic/test/agent.e2e.test.ts): auto-install, real `claude -p` / `codex exec` tasks, synced state checks (id `wtcag`, socks ports 22280-22379).
- **Typecheck:** `bun run typecheck`
- **Setup authoring guide / kit scripts:** [docs/authoring-setup.md](docs/authoring-setup.md); kit cache is `~/.cache/wtc/kit/<version>-<arch>-<contenthash>/` (`WTC_CACHE_DIR` overrides the root).
- **Layout:** single package `@lyonbot/wtc` ([packages/wtc](packages/wtc)): core logic [src/index.ts](packages/wtc/src/index.ts) (`exports "."`), setup types [src/setup/index.ts](packages/wtc/src/setup/index.ts) (`exports "./setup"`), CLI [src/cli/main.ts](packages/wtc/src/cli/main.ts), started via the node shim [bin/wtc.js](packages/wtc/bin/wtc.js) (`bin wtc`; checks bun >= `engines.bun`, prints install help if missing). **npm packaging:** `exports` serve TS source to bun and `dist/src/**/*.d.ts` as `types` (built by the `prepack` script in [package.json](packages/wtc/package.json)); [LICENSE](LICENSE) is copied to [packages/wtc/LICENSE](packages/wtc/LICENSE) and the npm page uses [packages/wtc/README.md](packages/wtc/README.md). Check contents with `cd packages/wtc && npm pack --dry-run`
- **Design:** [docs/superpowers/specs/2026-09-30-wtc-design.md](docs/superpowers/specs/2026-09-30-wtc-design.md); `wtc agent`: [2026-10-01-wtc-agent-design.md](docs/superpowers/specs/2026-10-01-wtc-agent-design.md)
- **Kit:** container helper `wtc-kit` (Go, [kit/go](kit/go)) + scripts in [kit/bin](kit/bin); `bun run build:kit` ([kit/build.sh](kit/build.sh)) cross-compiles to `kit/dist/` (gitignored; `bun test` builds it if missing via [kit/test/preload.ts](kit/test/preload.ts)). [kit/sync.sh](kit/sync.sh) (run by `build.sh` and the test preload) copies `kit/bin` + `kit/dist` into `packages/wtc/kit/` (gitignored, shipped in the npm tarball via `files`); `prepack` runs `build.sh`. Embedded/extracted by [packages/wtc/src/kit/embed.ts](packages/wtc/src/kit/embed.ts), which imports from `packages/wtc/kit`. Go tests: `cd kit/go && go test ./...`.
- **Instance lifecycle:** up/start/stop/restart/rm/ls/status in [packages/wtc/src/instance/instance.ts](packages/wtc/src/instance/instance.ts); container spec in [create-spec.ts](packages/wtc/src/instance/create-spec.ts), socks port allocation in [ports.ts](packages/wtc/src/instance/ports.ts), params in [params.ts](packages/wtc/src/instance/params.ts), known_hosts in [ssh.ts](packages/wtc/src/instance/ssh.ts). Create-time `container` config is resolved in [container.ts](packages/wtc/src/instance/container.ts) and snapshotted to `.wtc/run/<name>/config.json`; host-side `hooks.preBoot` runs from `preBoot()` in the same file (docs: [authoring-setup.md](docs/authoring-setup.md#host-side-hooks)). Host state lives in `<setup>/.wtc/{run,log}/<name>/`.
- **Ops + facade:** `createWtc` in [packages/wtc/src/wtc.ts](packages/wtc/src/wtc.ts); build (single image-build impl, used by `up`) in [ops/build.ts](packages/wtc/src/ops/build.ts), run/check/shell in [ops/exec.ts](packages/wtc/src/ops/exec.ts), agent runner in [ops/agent.ts](packages/wtc/src/ops/agent.ts) (definition API in [agent/define.ts](packages/wtc/src/agent/define.ts), built-in claude / codex definitions and host config collection in [src/agent/](packages/wtc/src/agent)), [logs.ts](packages/wtc/src/ops/logs.ts), [tunnel.ts](packages/wtc/src/ops/tunnel.ts), [open.ts](packages/wtc/src/ops/open.ts), [gc.ts](packages/wtc/src/ops/gc.ts), [doctor.ts](packages/wtc/src/ops/doctor.ts).
- **CLI:** commands in [packages/wtc/src/cli/main.ts](packages/wtc/src/cli/main.ts) (zero business logic), rendering in [render.ts](packages/wtc/src/cli/render.ts), agent guide in [packages/wtc/skill/SKILL.md](packages/wtc/skill/SKILL.md) (embedded; tests in [packages/wtc/test/cli](packages/wtc/test/cli) enforce every command and `WtcError` code is listed). `WTC_FAKE_RUNTIME=1` swaps in `FakeRuntime` (tests only).
- **Build:** `bun run build` = `build:kit` + `bun build --compile` -> `dist/wtc` (gitignored, embeds kit + SKILL.md). The CLI registers a Bun plugin ([main.ts](packages/wtc/src/cli/main.ts)) that serves `wtc`, `@lyonbot/wtc` and `@lyonbot/wtc/setup` as virtual modules (fallback when the package is not installed next to the setup), so a `wtc.setup.ts` works in both `bun` and compiled modes; editor types come from installing `@lyonbot/wtc` (see [docs/authoring-setup.md](docs/authoring-setup.md)).
